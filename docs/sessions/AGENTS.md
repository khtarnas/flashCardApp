# AGENTS.md — docs/sessions/

Chronological session logs capturing what was done, decided, and learned in each development session.

## File naming

`{YYYY-MM-DD}-{short-title}.md` (e.g., `2026-05-02-kickoff.md`)

## Template

Each session log should include:
- **Summary** — One-paragraph overview
- **What we did** — Bullet list of activities
- **Decisions made** — Reference decision IDs from `docs/decisions.md`
- **Documents created/modified** — List of files changed
- **Open items for next session** — What to pick up next

## Directives

- Create a new session log at the start of each working session.
- Keep entries concise — document what's worth documenting.
- Reference decision IDs rather than re-explaining decisions.
