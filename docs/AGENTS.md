# AGENTS.md — docs/

Product and technical documentation for HanaHou.

## Contents

| File | Purpose |
|------|---------|
| `p0.md` | P0 (must-have) feature scope and requirements |
| `p1.md` | P1 (should-have) feature scope |
| `roadmap.md` | Full feature backlog across all priority tiers |
| `data-model.md` | Core Data entity specifications |
| `decisions.md` | Decision log with rationale (append new decisions at top) |
| `open-questions.md` | Unresolved questions (move to decisions.md when answered) |
| `learnings.md` | Personal knowledge journal — concepts learned while building (for the human, not the agent) |
| `sessions/` | Per-session development logs |

## Directives

- When a decision is made, add it to `decisions.md` with date and rationale.
- When a question is answered, remove it from `open-questions.md` and record the decision.
- Priority tier docs (`p0.md`, `p1.md`, etc.) define scope — do not add features without updating the relevant tier doc.
