# P1 — Should Have

Important features that enhance the experience but aren't required for basic usability.

## Features (tentative — to be refined)

### Apple Pencil Integration
- Draw/write on card front or back using Apple Pencil
- Store PKDrawing data in Core Data
- Display handwritten content alongside or instead of text

### Card-Deck Many-to-Many (UI)
- Add an existing card to an additional deck
- View which decks a card belongs to
- Remove a card from a deck without deleting it

### Study Mode Enhancements
- Self-grading (got it / missed it) per card
- Study session summary (cards reviewed, accuracy)
- Shuffle mode

## Status

P1 scope is not yet finalized. Features will be refined as P0 is completed and open questions are resolved.
