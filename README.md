# HanaHou 🌺

**"One more time"** — A personal iPadOS flashcard app for language learning.

## What is this?

HanaHou is an offline-first flashcard app built with SwiftUI and Core Data, designed for focused language study on iPad. It prioritizes a clean study experience with plans for Apple Pencil integration, spaced repetition, and AI-powered features.

## Status

🔴 **Pre-development** — Project structure and documentation established. No custom functionality implemented yet.

## Tech Stack

- **Swift** / **SwiftUI** / **Core Data**
- **iPadOS only**
- **Offline-first** (no network calls)

## Getting Started

1. Clone the repo: `git clone https://github.com/khtarnas/flashCardApp.git`
2. Open `HanaHou.xcodeproj` in Xcode
3. Select an iPad simulator
4. Build and run (⌘R)
5. Run tests (⌘U)
